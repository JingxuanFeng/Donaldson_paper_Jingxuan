…
This code takes raw_data, keeps three measurements, fixes a few entries, converts them to numbers, and removes rows with missing values. The result is stored as cleaned_data.
The |> symbol passes the result of one step into the next:

janitor::clean_names() changes column names to a consistent style, such as Wing Width (mm) → wing_width_mm.
select(...) keeps only wing width, wing length, and first-timer flying time.
filter(wing_width_mm != "caw") removes rows where wing width contains the text "caw" instead of a measurement.
The three mutate(... if_else(...)) steps make specific corrections: "1,35" → "1.35" for flying time, and "490" → "49" and "6" → "60" for wing width. Other values stay as they are.
as.numeric(...) converts all three columns from text to numbers so they can be analysed mathematically.
rename(...) gives them shorter names: flying_time, width, and length.
tidyr::drop_na() removes any row missing any of those three values.
The order matters: the unusual text values are corrected before as.numeric() tries to convert the columns.

how do I simulate continuous times


For your TTC simulation, represent the time of day as a number of hours since midnight. runif() generates continuous numbers:
set.seed(2453)
n <- 1000

time_hours <- runif(n, min = 0, max = 24)

For example, 8.5 means 8:30 a.m., and 16.25 means 4:15 p.m. You can then use the same peak definitions as in your analysis:
period <- dplyr::case_when(
  time_hours >= 6.5 & time_hours < 10   ~ "morning peak",
  time_hours >= 15.5 & time_hours < 19  ~ "afternoon peak",
  TRUE                                  ~ "other hours"
)

This is a simple starting simulation: runif() makes every time of day equally likely. If your goal is to mimic recorded TTC incidents more closely, you can later make some hours more likely than others. Keep the random seed so rerunning the script produces the same simulated times.



I want to keep the format:00:00:00, how do I simulate the time


Generate a random number of seconds after midnight, then format it as HH:MM:SS:
set.seed(2453)
n <- 1000

seconds <- floor(runif(n, min = 0, max = 24 * 60 * 60))

time <- sprintf(
  "%02d:%02d:%02d",
  seconds %/% 3600,
  (seconds %% 3600) %/% 60,
  seconds %% 60
)

head(time)

For example, a result might be "08:34:12". Each part is padded to two digits, so midnight appears as "00:00:00". The simulated times have one-second precision; runif() makes times across the day equally likely.

minutes is the number of minutes since midnight. Dividing it by 60 separates that number into hours and leftover minutes.
For example, suppose minutes is 514:

514 %/% 60   # 8
514 %% 60    # 34

%/% gives the whole-number quotient: 8 complete hours.
%% gives the remainder: 34 minutes left over.
So 514 minutes after midnight is 08:34:00. In your code, R does this calculation for every value in the minutes vector.
